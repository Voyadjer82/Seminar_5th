# Mentor's Seminar — задания на Go

Преподаватель: Владислав Шевченко.

Каждое задание находится в отдельной папке и содержит один файл `main.go`.

| Папка | Задание |
| --- | --- |
| task01 | Калькулятор с проверкой деления на ноль |
| task02 | Анализ целого числа |
| task03 | Сумма и среднее от 1 до N |
| task04 | Таблица умножения через функцию |
| task05 | Максимум и минимум из N чисел |
| task06 | Количество положительных, отрицательных чисел и нулей |
| task07 | Сумма чётных чисел, делящихся на 3 |
| task08 | Проверка простого числа |
| task09 | Мини-банкомат |
| task10 | Статистика последовательности |

## Запуск

Откройте папку проекта в VS Code и запустите нужное задание в терминале:

```sh
go run ./task01
```

Для других заданий замените `task01` на нужную папку, например `task10`.

Вводите числа через пробел или с новой строки. Для дробной части используйте точку. В калькуляторе сначала введите два числа, затем операцию. В заданиях 5, 6 и 10 сначала введите количество чисел, затем сами числа.

В заданиях 2, 3, 4, 7, 8 и 10 используются целые числа. В заданиях 1, 5, 6 и 9 допускаются дробные числа. Программы рассчитаны на корректный числовой ввод.
